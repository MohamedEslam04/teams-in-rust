# appearance

## Overview
IronTeams appearance and general preferences: theme, accent, density, font scale, accessibility switches, text snippets, the app bar's order and hidden entries, language and date/time format state, plus a reader for the XDG desktop portal (D-Bus) settings. Each preferences type loads leniently from a JSON file in the config directory and saves atomically. The theme model (tokens, OKLCH derivation, contrast report, `themes.json`, theme choice, resolver, share line) lives here too; it is not wired into the UI yet.

## Invariants
- Font scale is clamped to 0.75..=2.0 on load, set, save and resolve; NaN or infinite becomes 1.0 [prefs.rs:clamp_font_scale]. Effective scale = clamp(base x 1.25 if larger text, 0.75, 2.5) [accessibility.rs:effective_font_scale].
- Loading never fails: a missing, corrupt or wrong-shape file yields defaults, and a bad field resets only that field (`#[serde(default)]` plus lenient deserializers) [store.rs:load_json, lenient].
- Saving is atomic: temp file `.<name>.<pid>.tmp` in the same dir, `sync_all`, rename; the temp is removed on failure [store.rs:save_json].
- Theme resolution: explicit Light/Dark wins; `System` follows the portal; no preference or no portal gives Dark [resolve.rs:resolve_theme]. Accent: user value, else portal accent [resolve.rs:resolve_accent].
- `AutoSwitch` On/Off always win; Auto reduced-motion is true only when the portal reports animations disabled [accessibility.rs:resolve_reduced_motion].
- `SnippetPrefs.items == None` means never saved (built-ins returned); `Some(vec![])` stays empty [snippets.rs:SnippetPrefs::effective].
- Language: `resolve_language` always returns an available language (user choice, system, fallback `en`); `system_language_from` checks `LANGUAGE`, `LC_ALL`, `LC_MESSAGES`, `LANG` in that order [general.rs:resolve_language, system_language_from].
- `check_updates` and `auto_update` are always `true`: whatever the file holds is ignored (the fields stay so old files load) [general.rs:always_on]. `beta_updates` defaults to off.
- `wheel_speed` is clamped to 1.0..=5.0; a value that is not a number or is not finite gives 2.5 [general.rs:clamp_wheel_speed, de_wheel_speed].
- `quick_reactions` (hover-bar reaction keys) is trimmed, de-duplicated and cut to 6; a value that is not a list of strings, or empty, gives like/heart/laugh/surprised [general.rs:de_quick_reactions].
- `renderer`: `IRONTEAMS_RENDERER` (passed in by the caller as `env`) wins over the saved choice; an empty value counts as unset and an unknown value gives `Cpu`. `Cpu` is the default and also the result of a bad saved value [renderer.rs:resolve, Renderer::parse].
- Portal `read`/`watch` never panic. `read` yields `Ok(None)` for a missing session bus, portal service or key; `watch` yields `Ok(None)` only when there is no session bus, and returns `Err(PortalError)` for a failed proxy or signal subscription. Other errors are `Err(PortalError)` [portal.rs:is_absent, read, watch].
- `formats::set_from` must be called at start and on every preference change; the shared format and zone state is process-wide [formats.rs:CHOICE, ZONE].
- Contrast: derived themes move only drawn text tokens (`fg`, `fg-strong`, `fg-muted`, `fg-subtle`, `accent`, `mention`, `danger-text`, `warning`, `success`) in OKLCH lightness steps of 0.005 until every pair of [themes.rs:pair_list] passes (4.5:1 text, 3:1 muted text, icons, accent, mention); when none passes the best worst-pair colour stays and `Report.low_contrast` is set. `keep_original` moves nothing. `Base` keeps what the user picked. The eight derived built-ins must pass with no adjustment [themes.rs:adjust, theme_tokens].
- IronTeams Dark and Light (`ThemeDef.literal`) are never adjusted and never `low_contrast`; their report only measures. The accent setting applies to them alone (today's `mix` rules); every other theme ignores it [themes.rs:theme_tokens, tokens.rs:literal].
- The nav set copies the accent group, `mention`, `bubble-*` and `code-bg` from the content set and is checked only on tokens it derives itself [themes.rs:derive, NAV_GROUPS].
- Share line: refused before any other parsing when over 200 scalar values (or 800 bytes); prefix, version `1`, name (1 to 40 scalar values, no `:`, no control or Cf character except U+200C and U+200D) and exactly 8 `#rrggbb` colours are all checked; nothing from the line is used as a path, font or markup [share.rs:parse, check_name].
- `themes.json` is separate from `appearance.json`, so builds without themes never touch it. The loader reads each field on its own: a wrong-shape field takes its default, a bad custom entry (unreadable, id not `custom:`, bad name, repeated id, past the first 50) is skipped and counted in `LoadNote.skipped`, a schedule minute above 1439 drops `choice`, and a file that is not a JSON object is renamed `themes.json.bad` (replacing an older one) before defaults are used. The crate does not log; the caller logs `LoadNote` [themes.rs:ThemesFile::load_from].
- Resolution: an account entry beats the app choice (`themes.choice`, else the legacy `appearance.json` `theme`); a missing id falls back by layer (account to app choice, pair slot to the built-in of its kind, call to same-as-app, fixed to the default) and is recorded in `ResolvedLook.fallbacks`; deleting a theme leaves references in place. A pair is dark when the portal says Dark, no preference or nothing, or inside the schedule's dark window (`in_window(dark_from, light_from, now)`, equal times mean always light). High contrast gives content, nav and call the contrast palette of the theme's kind with an empty report [resolve.rs:resolve_look].
- The legacy `appearance.json` `theme` is written from the kind of the effective choice: `Fixed` light theme `Light`, dark theme `Dark`, missing theme or any `Pair` `System` [themes.rs:legacy_theme].
- Custom theme names are unique ignoring case against built-ins and other custom themes (" (2)", " (3)", cut to 40); at most 50 custom themes [themes.rs:ThemesFile::unique_name, add].
- `config_dir`: `IRONTEAMS_HOME` (or the legacy `KELMA_HOME`, via `compat::var`) overrides to `<home>/config`, else `ProjectDirs("ironteams")`, else `Error::NoHome` [store.rs:config_dir].

## Side Effects
- Disk read and write of `appearance.json`, `accessibility.json`, `snippets.json`, `rail.json`, `shortcuts.json`, `general.json` and `themes.json` in the config dir (create_dir_all, temp write, fsync, rename) [store.rs:save_json].
- Calls `compat::migrate_legacy_dirs()` on every `config_dir()` call when `IRONTEAMS_HOME` is unset [store.rs:config_dir].
- D-Bus: session bus connection to `org.freedesktop.portal.Desktop` (`ReadOne`, fallback `Read`, and `SettingChanged` subscription) [portal.rs:connect, read_key, watch].
- Global state: `static CURRENT` RwLock in `language`, `CHOICE` and `ZONE` RwLocks in `formats`; poisoning is ignored [language.rs, formats.rs].
- Reads env vars `LANGUAGE`, `LC_ALL`, `LC_MESSAGES`, `LANG`, `IRONTEAMS_HOME` and the legacy `KELMA_HOME` [store.rs:config_dir]; reads local clock and time zone via chrono [general.rs:system_language, formats.rs].
