# Bundled fonts

Both are color emoji fonts, bundled because Slint's renderer supports COLRv0 and CBDT color glyphs
but not COLRv1, which is the format most Linux distributions ship for their emoji font. `main.rs`
tries them in this order.

## `FluentEmoji3D.ttf`

Microsoft's [Fluent Emoji](https://github.com/microsoft/fluentui-emoji), 3D style, which is the
emoji set Teams shows. It is a CBDT/CBLC bitmap font (one 96 px PNG strike per emoji, 3145 glyphs
with all five skin tones), generated by `gen/fluent_emoji.py` from the repository's `assets/*/3D`
PNGs (commit `1ffb34c752ecf5d402f04cfb4b392c77f57c54bc`). ZWJ sequences, keycaps and skin tones are
GSUB ligatures. Fluent Emoji has no country flags, so flags fall through to Twemoji.

- Graphics: Copyright (c) Microsoft Corporation, licensed under the MIT License, see
  `LICENSE-fluentui-emoji`.
- Generator script: part of IronTeams.

To regenerate it, follow the usage note at the top of `gen/fluent_emoji.py`. The font is checked in
because packaging builds (Flatpak) are offline.

## `TwemojiMozilla.ttf`

Twemoji in COLRv0 format, from [mozilla/twemoji-colr](https://github.com/mozilla/twemoji-colr)
v0.7.0. It is the fallback for what Fluent Emoji lacks (flags and the newest emoji).

  [CC-BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- Font build tooling: Mozilla, Apache-2.0.
