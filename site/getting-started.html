Getting started

From download to your first chat takes a few minutes.

1. Install

Take the file for your system from the download section, then follow the install guide for that format. If you are on Linux and unsure, take the AppImage.

2. Start it

Start IronTeams from your launcher. An AppImage or tar.gz copy has no launcher entry until you have run it once: it adds the entry itself. A Flatpak also starts with flatpak run io.github.mohamedeslam04.ironteams.

3. Sign in

On first start IronTeams shows a code. Open the link it shows, enter the code and sign in with your work account. That is the normal Microsoft sign-in page, and it works with multi-factor authentication.

IronTeams keeps the refresh token in your system keyring (KWallet or GNOME Keyring on Linux, Credential Manager on Windows, the login Keychain on macOS), never in a file. You can add several accounts and guest organizations.

To switch, open the profile menu and pick an account in its Accounts section; Add account and Manage accounts are there too. IronTeams restarts on the other account, which takes a moment. If a call, a voice message you are recording, messages waiting to be sent or an upload would be cut short, a dialog lists it and Cancel keeps everything as it was. Your drafts are saved either way. Each account reopens on its own last chat and keeps its own media cache, and the menu shows the unread count each account had when you last used it. Starting IronTeams a second time just brings the running window forward.

On Linux, IronTeams needs a Secret Service provider such as GNOME Keyring or KWallet to keep you signed in.

Try it without an account

Demo mode shows sample data with no account and no network:

IRONTEAMS_DEMO=1 ironteams

With an AppImage, run IRONTEAMS_DEMO=1 ./IronTeams.AppImage instead.

Settings worth a look

  • Appearance: theme (ten built-in themes: one theme, follow the system, or a light and a dark theme on a schedule), accent, density and text size. Reset theme in the command palette puts the default back.
  • Language: the app language, with Arabic for the main screens. Arabic, English and mixed text show in the right direction per paragraph.
  • Accounts and Storage: add, switch and remove accounts, and see how much media each account keeps (Clear media clears only the active account).
  • Notifications: including whether IronTeams downloads Teams’ original sounds.
  • About › Updates: beta updates and Check now (updates themselves cannot be turned off). See Updates.

Before you use a work account

IronTeams is unofficial. It talks to the same internal endpoints the Teams web client uses, and your organization’s policies may not allow third-party clients. Check with your IT team first. See the disclaimer.

If something does not work, Troubleshooting shows how to write a local problem report.
