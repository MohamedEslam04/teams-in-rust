Troubleshooting

IronTeams collects no telemetry and never uploads anything. When something breaks, you write a local bundle, read it, and attach it to an issue yourself.

Report a problem

ironteams --report-problem

The same command is in the launcher’s right-click menu as Report a problem. To include a log, run IronTeams with logging on, then write the report with ironteams-cli:

IRONTEAMS_LOG=ironteams=debug ironteams 2> ironteams.log
ironteams-cli diag --log ironteams.log

The .tar.gz goes to your Downloads folder (--out PATH changes that). It holds the IronTeams version, OS and desktop facts, the non-secret config and the logs you pass in. Tokens, cookies, e-mail addresses, MRIs, conversation ids, GUIDs (tenant ids included), tenant domains and user names are replaced by placeholders. The keyring and the message cache are never read.

Read the bundle before you attach it. It is a plain archive on your disk.

Environment variables

VariableEffect
IRONTEAMS_RENDERER=femtovgGPU renderer instead of the default software renderer (uses more memory). It beats the choice in Settings › General › Performance.
IRONTEAMS_LOG=ironteams=info,teams_proto=infoLogging to stderr. Tokens are never logged.
IRONTEAMS_DEMO=1Offline demo with sample data: no account, no network.
IRONTEAMS_HOME=<dir>Keep config, cache and data under <dir>.
IRONTEAMS_GST_LAUNCHUse another gst-launch-1.0 for camera and screen sharing.

The old KELMA_* names still work when the IRONTEAMS_* one is not set. IronTeams was called kelma before. On the first start after the rename, the old kelma config, data and cache folders move to ironteams, and a saved sign-in under the old keyring name moves to the new one when it is first read, so you stay signed in.

Common problems

Windows SmartScreen warns about the installer

The installer is not signed yet. Choose More info, then Run anyway.

macOS will not open the .pkg

The package is not signed or notarized yet. Open it with right click, then Open.

Recording a voice message says “Install ffmpeg”

IronTeams runs ffmpeg to encode recordings. Install ffmpeg. In the Flatpak the sandbox has no ffmpeg, so recording does not work there yet, while playing voice messages does.

Camera or screen sharing does not work on Windows or macOS

Install the GStreamer runtime. Both are compile-only on these systems for now. See Platforms and requirements.

It asks me to sign in again every time (Linux)

IronTeams keeps the refresh token in the Secret Service. Check that GNOME Keyring or KWallet runs and is unlocked.

It does not update

Only copies installed from Setup.exe, the .pkg or the AppImage update themselves. Look at Settings › About › Updates, and press Check now. If a new version failed to start three times, automatic updates pause and a banner offers to go back to the previous version.

It uses more memory than I expected

The default is the software renderer. IRONTEAMS_RENDERER=femtovg switches to the GPU renderer, which uses more memory.

Open an issue

Describe what you did and what you expected, name your system and the IronTeams version, and attach the report bundle. Open it on GitHub issues. For how IronTeams is built, read docs/ARCHITECTURE.md.
