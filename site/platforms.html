Platforms and requirements

IronTeams runs on Linux, Windows and macOS. Linux is the one used every day.

What has been tried

CI runs clippy and the whole test suite on Linux on every push. Windows (x86_64) and macOS (Apple Silicon and Intel) run the whole test suite before their files are added to a release. The CI runners have no screen, camera or microphone, so anything that needs one is only checked to build there.

Daily use is on Linux (KDE Plasma, Wayland). Nothing has been tried on real Windows or macOS hardware yet.

The downloads are for 64-bit systems: x86_64 on Linux and Windows, and Apple Silicon or Intel on macOS.

What you need

Linux

  • A Secret Service provider (GNOME Keyring or KWallet) to keep your sign-in.
  • xdg-desktop-portal and an emoji font help, and are recommended.
  • ffmpeg for recording voice messages and for video clips.
  • A Chromium-family browser for app tabs (the web host).

Windows

  • The GStreamer runtime for camera and screen sharing.
  • ffmpeg for video clips.
  • Edge or Chrome for app tabs.

macOS

  • The GStreamer runtime for camera and screen sharing.
  • ffmpeg for video clips.
  • Chrome, Edge or Brave in /Applications for app tabs.

Why ffmpeg and GStreamer

IronTeams is GPL-3.0-or-later and must not link fdk-aac. So Linux runs the system ffmpeg for the AAC encoder, while Windows and macOS use the encoder that comes with the system. Media Foundation is loaded at run time, so Windows N editions without the Media Feature Pack still start and fall back to ffmpeg.

GStreamer is not bundled. IRONTEAMS_GST_LAUNCH points IronTeams at another gst-launch-1.0.
