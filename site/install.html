Install IronTeams

Pick one file, run the commands below, then start IronTeams from your launcher. The download buttons on this page read the latest release from GitHub.

Which file?

Linux is the system IronTeams is used on every day. The Windows and macOS builds pass their tests in CI but have not been tried on real hardware yet. See Platforms and requirements.

Linux: AppImage

Download AppImage

One file, no install step. Put it somewhere permanent, make it executable and run it:

chmod +x IronTeams.AppImage
./IronTeams.AppImage

An AppImage updates itself (see Updates). On start IronTeams writes a launcher entry under ~/.local/share/applications that points at the file, and rewrites it if you move the file.

Linux: RPM

Download RPM

Built for Fedora. Install it from the folder you downloaded it to:

sudo dnf install ./ironteams-*.rpm

The RPM is not in a package repository yet, so to move to a newer version you download the new file and install it the same way. On other distributions, take the AppImage.

Linux: Flatpak

Download Flatpak

flatpak install --user ./ironteams.flatpak
flatpak run io.github.mohamedeslam04.ironteams

The bundle is built against the Freedesktop 26.08 runtime. If Flatpak does not offer to fetch it, install it from Flathub first:

flatpak install flathub org.freedesktop.Platform//26.08

The sandbox allows the network, Wayland and X11, PipeWire, notifications and the Secret Service, and nothing else. One known gap: recording voice messages needs ffmpeg, which the Freedesktop runtime does not include, so recording says “Install ffmpeg” inside the sandbox. Playing voice messages works.

Linux: tar.gz

Download tar.gz

The archive holds the ironteams binary, the desktop file, the icon, the AppStream metadata, the license and the README, in a folder named after the version.

tar -xzf IronTeams-*-linux-x86_64.tar.gz
./IronTeams-*-linux-x86_64/ironteams

A copy from the tarball never replaces itself. IronTeams needs a Secret Service provider (GNOME Keyring or KWallet) to keep your sign-in. When no package installed it, IronTeams writes its own launcher entry on start, as it does for the AppImage.

Windows

Setup.exe is a per-user install: no administrator needed, and it updates itself.

Download Setup.exe

The installer is not signed yet. Windows SmartScreen asks once: choose More info, then Run anyway.

Portable zip is the same app without an installer: unzip it to a folder of your choice and start the program inside.

Download portable zip

The Windows build passes its tests in CI but has not been tried on real Windows hardware yet. Camera and screen sharing need the GStreamer runtime; see Platforms and requirements.

macOS

Take the package for your chip: Apple Silicon (M-series) or Intel. Both update themselves.

Download .pkg for Apple Silicon

Download .pkg for Intel

The package is not signed or notarized yet, so macOS asks before the first install: open the .pkg with right click, then Open.

The macOS build passes its tests in CI but has not been tried on real Mac hardware yet.

Updates

Copies installed from Setup.exe, the .pkg or the AppImage update themselves with Velopack:

  • About 45 seconds after the start, then every 6 hours, IronTeams looks at the GitHub releases for a newer version. It downloads it in the background, and only the parts that changed when it can. The size and SHA-256 of every download are checked, and the feed is read over HTTPS from github.com only.
  • Nothing is installed while you work. A banner says “IronTeams <version> is ready” with Restart to update. If you do not click it, the update is installed when you quit. If a download or the install fails, the current version keeps running and the next check tries again.
  • Before a new version first opens its data, your message caches and settings are copied to backup-<old version> in the data folder. The last two are kept.
  • If a new version fails to start three times in a row, automatic updates pause and a banner offers to go back to the version before.
  • Updates cannot be turned off: new versions are always downloaded and installed when you restart or quit. Settings › About › Updates has Get beta updates (off) and Check now.

Copies from the tarball, RPM, Flatpak, AUR or cargo never replace themselves. For these, Settings › About checks GitHub for the latest release once per start, shows a banner when there is one, and never downloads anything. That check cannot be turned off.

The first Velopack release has to be installed by hand once, also for users of an older MSI or .dmg. Every release after it arrives on its own.

Uninstall

  • AppImage and tar.gz: delete the file or folder. Also delete the launcher entry IronTeams wrote, ~/.local/share/applications/io.github.mohamedeslam04.ironteams.desktop, and its icon under ~/.local/share/icons/hicolor/scalable/apps/.
  • RPM: sudo dnf remove ironteams
  • Flatpak: flatpak uninstall --user io.github.mohamedeslam04.ironteams
  • Windows and macOS: the project does not document uninstalling these builds yet.

Uninstalling does not delete your settings or cache. They live in folders named ironteams (or in the folder you set with IRONTEAMS_HOME), and your sign-in is kept in the system keyring.

Build from source

You need Rust (through rustup), Git, and the development headers for fontconfig, xkbcommon and D-Bus:

# Fedora
sudo dnf install fontconfig-devel libxkbcommon-devel dbus-devel
# Debian and Ubuntu
sudo apt install libfontconfig1-dev libxkbcommon-dev libdbus-1-dev pkg-config
git clone https://github.com/MohamedEslam04/teams-in-rust && cd teams-in-rust
./packaging/install.sh

The script builds IronTeams and installs the binary, the desktop file and the icon to ~/.local.

On Arch, the packaging/aur/PKGBUILD builds the -git package from the latest commit with makepkg -si. To build the Flatpak or the RPM yourself, each folder under packaging/ has a README. On Windows (MSVC build tools) and macOS (Xcode command line tools) you need CMake as well, and cargo build --release -p ironteams builds the app.
